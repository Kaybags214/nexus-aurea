# Check 2 — Parties and routing

- [ ] Shipper name **and full address**, box 1 — a name alone is a finding
- [ ] Consignee name and full address, box 2
- [ ] Issuing agent name and IATA code
- [ ] Airport of departure named
- [ ] Airport of destination named
- [ ] Requested routing and to-by carrier fields consistent with those airports

## Against the other documents

- [ ] Shipper matches the invoice and packing list **exactly**
- [ ] Consignee matches the invoice and packing list exactly

Severity: an abbreviated or truncated party name is **Major**. A genuinely different party is
**Critical** — it may be an undeclared change of consignee.

## Notify party and account fields

- [ ] Where a notify party is required by the lane or the letter of credit, it is present
- [ ] Accounting information does not contradict the declared value fields in check 5
