# Check 5 — Declarations, signatures and execution

- [ ] Declared value for carriage completed, or **"NVD"** entered
- [ ] Declared value for customs completed, or **"NCV"** entered
- [ ] Amount of insurance completed, or **"XXX"** / "NIL" entered
- [ ] Shipper's certification box signed
- [ ] Carrier execution box shows place, date and signature
- [ ] Currency stated where a value is declared

## On blank value fields

A blank declared-value field is **Major**, not Minor. Blank is ambiguous — it is not the same
as NVD, and carriers and customs read the ambiguity differently. The field must say something.

## Alterations

- [ ] No overwriting or erasure in the value, weight or party fields

An altered AWB is not correctable in the report. The finding is that a clean replacement is
needed, same as an altered DGD.

## Dates

- [ ] Execution date is not earlier than the shipper's certification date
- [ ] Execution date is consistent with the invoice and packing list dates
