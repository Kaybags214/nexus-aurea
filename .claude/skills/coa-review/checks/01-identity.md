# Check 1 — Identity and lot traceability

- [ ] Product name and strength / presentation
- [ ] Manufacturer named, with site
- [ ] **Lot / batch number** present
- [ ] Quantity or batch size stated
- [ ] Storage condition stated on the certificate

## Traceability to the shipment

The CoA must belong to what is actually in the box.

- [ ] Lot number matches the **packing list**
- [ ] Lot number matches the **commercial invoice**
- [ ] Lot number matches the **physical label** where visible in the images
- [ ] Product description matches the AWB goods description

## A lot mismatch is Critical

A CoA for a different lot is not a paperwork slip — the shipment is travelling with no valid
certificate at all, and the mismatch usually means one of the two documents describes the wrong
material.

Do not resolve it by assuming a typo. Name both values and which document each came from.

## Storage condition

Record the storage condition from the CoA and compare it to the shipping condition on the AWB.
A CoA saying +2/+8 on a shipment tendered as controlled ambient is a finding, and it feeds
`excursion-assessment` check 1 as the governing range.
