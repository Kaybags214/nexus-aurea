# Check 1 — Header, routing and pagination

- [ ] Shipper name and full address
- [ ] Consignee name and full address
- [ ] Air Waybill number, matching the AWB itself
- [ ] Airport of departure named
- [ ] Airport of destination named
- [ ] **Page n of n** completed on every page

## Pagination

A multi-page declaration missing "page 2 of 2" is Critical, not clerical. Acceptance has no way
to know a page is absent, and an undeclared entry can travel unnoticed.

## Transport details

- [ ] The shipment type line and the routing are consistent with the airports named
- [ ] Where transit states are involved, note them — check 2 needs them for state variations
