# Check 1 — Header, routing and pagination

- [ ] Shipper name and full address
- [ ] Consignee name and full address
- [ ] Air Waybill number, matching the AWB itself
- [ ] Airport of departure named
- [ ] Airport of destination named
- [ ] **Page n of n** completed on every page

## Pagination

A multi-page declaration missing "page 2 of 2" is Critical, not clerical. Acceptance has no way
to know a page is absent, and an undeclared entry can travel unnoticed.

## Shipment type — radioactive or non-radioactive

The form carries two shipment-type lines. Exactly one survives, the same way the aircraft lines
in check 3 work.

- [ ] **Non-radioactive** marked where the entries are non-radioactive
- [ ] **Radioactive** marked only where the shipment actually contains radioactive material
- [ ] The non-applicable line is deleted or left clear, not both marked
- [ ] The selection **agrees with the entries in check 2**

Marking radioactive on a shipment with no radioactive entry is **Critical**. It sends the
shipment into an acceptance path with different segregation, documentation, labelling and
handling requirements than the goods actually need — and it is a plain contradiction of the
declaration's own classification block.

Both lines blank is equally Critical: acceptance cannot tell what was declared.

This check exists because a real declaration was found marked radioactive on a dry ice and
biological substance shipment, and no check asked about the field. Read it every time.
