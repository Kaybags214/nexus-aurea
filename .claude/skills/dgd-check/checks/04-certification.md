# Check 4 — Emergency contact and certification

- [ ] Certification statement intact and unaltered
- [ ] Name and title of signatory
- [ ] Place and date
- [ ] Signature present
- [ ] Additional handling information completed where required

## The 24-hour emergency response number — establish that it applies first

**This is not an unconditional base-IATA requirement on every declaration.** Where it applies is
driven by state and operator variations for the actual routing, with commodity-specific
treatment. An earlier version of this file made a missing number an automatic Critical
worldwide, which would place compliant shipments on hold.

Work it in this order:

- [ ] **Identify the routing** — origin, transit states, destination, and the operator
- [ ] **Identify the applicable variations** for that routing —
      `standards-of-precedence.md` §1 puts state variations at the top
- [ ] **Determine whether those variations require the number for this consignment.** If the
      variations cannot be established, this is `unverified` — record the routing you could not
      resolve and raise no finding
- [ ] Where it is required: number present, includes country code, and is a monitored emergency
      contact rather than an office line

Where it is required and absent, that is a Critical. Where applicability is unverified, the
finding is that the routing and variations need checking — never that the declaration is
defective.

## Critical conditions

- **Unsigned declaration.** No exceptions.
- **A required 24-hour number that is missing**, or a number that is plainly an office line
  rather than a monitored emergency contact — *once the requirement is established above.*

## On the certification statement

The statement is fixed wording. Any edit to it — softened, shortened, partially struck — voids
the declaration. The finding is that a fresh form is required, not that the wording be restored.

## Signatory

The signatory must be a person, named and titled. "Shipping Dept" is not a signatory. Note that
verifying the signatory's DG training currency is outside this skill's reach — flag it as a
question for the operator rather than asserting it was or was not valid.
