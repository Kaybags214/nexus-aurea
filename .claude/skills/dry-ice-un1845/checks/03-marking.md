# Check 3 — Marking, labelling and packaging

- [ ] Class 9 label on each package
- [ ] UN1845 and the proper shipping name marked on the outer package
- [ ] Shipper and consignee name and address marked on the package
- [ ] Net weight marked on the package where required
- [ ] Packaging permits the release of carbon dioxide gas

A sealed, non-venting outer is **Critical** — it is a rupture risk, not a paperwork defect.

## Overpacks

If packages are combined in an overpack:

- [ ] The overpack is marked **"OVERPACK"**
- [ ] The marks and labels required on each inner package are either visible through the
      overpack or reproduced on its outside
- [ ] The total dry ice net weight for the overpack is stated, and reconciles with the sum of
      the packages inside it

An overpack whose inner marks are hidden and not reproduced is Critical — acceptance cannot
verify what is inside without opening it.
