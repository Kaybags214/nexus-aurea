# Check 4 — Marking and labelling

## The lithium battery mark

Section II shipments require the **lithium battery mark** on the outer package.

- [ ] Mark present on the package
- [ ] **UN number(s)** shown on the mark — UN3480, UN3481, UN3090 or UN3091 as applicable
- [ ] **Telephone number** for additional information shown on the mark
- [ ] Mark dimensions meet the requirement — **verify size against the DGR 67th ed.**
- [ ] Mark is legible, durable, and contrasts with the package

The telephone number is part of the mark, not optional decoration. A mark without one is
incomplete.

## Class 9 lithium battery label

- [ ] Where the section requires the Class 9 lithium battery hazard label, it is affixed
- [ ] The label is the **lithium battery** version of Class 9, not the generic miscellaneous
      Class 9 label — they are different labels and are not interchangeable

## Cargo Aircraft Only label

- [ ] Affixed where the shipment is restricted to cargo aircraft (check 3)

## Other package marking

- [ ] Shipper and consignee name and address on the package
- [ ] Package is of a type and quality able to prevent movement and short circuit

## From a photograph

Where the submission is a transcription or a document scan rather than package photographs,
none of this is verifiable. Record every marking item as **"cannot verify from image"** and
request package photographs. Do not report absence you could not have seen.
