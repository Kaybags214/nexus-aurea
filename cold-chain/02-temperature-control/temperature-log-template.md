# Cold Chain Temperature Log — Template

Purpose: Manual temperature-monitoring log template aligned with GDP/GMP documentation expectations (EU GDP Guidelines, WHO TRS 961, USP <1079> series). Original template, ready to use directly or adapt into a spreadsheet.

## Pre-Shipment / Setup Fields

- Shipment or lane ID
- Product / commodity
- Required temperature range (e.g., 2°C–8°C)
- Data logger ID and calibration certificate reference
- Logger start time and starting operator
- Ambient conditions at start

## Excursion Handling

- [ ] Excursion identified (date/time, duration, temperature reached)
- [ ] Immediate corrective action taken (documented)
- [ ] Product disposition decision (release, quarantine, reject) and rationale
- [ ] Root cause investigation opened
- [ ] Notification to relevant parties (consignee, QA, carrier) logged

## Close-Out Fields

- Logger stop time and operator
- Logger data downloaded and archived (reference/location)
- Final disposition of shipment
- Retention period confirmed (per applicable GDP requirement)

## Review / Practice Checklist

- Are there any gaps in the time series (missing readings)?
- Do all readings fall within the stated required range, and if not, is an excursion record present?
- Is the logger calibration certificate current as of the shipment date?
- Is the retention period for this log documented and met?
