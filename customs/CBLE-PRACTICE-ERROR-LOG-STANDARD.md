# CBLE — Practice and Error-Log Standard
Status: Study methodology, not a substitute for official exam references
Captured: 2026-10-27

## Practice protocol
Use official CBP exams and corresponding official answer keys. For each missed, guessed, or slow question, record:
| Exam/date | Q# | My answer | Official answer | Exact authority | Error type | Correct rule in my words | Follow-up drill |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Suggested error types: READ (question misread), LAW (rule unknown), CITE (could not locate reference), MATH, HTS (classification), TIME.

## Study rules
- Link every learned takeaway to the official answer key and controlling CFR/HTSUS/CBP material for the relevant administration.
- Separate Part 111 broker regulation, Parts 141–143 entry procedures, Part 152 classification/appraisement, Part 159 liquidation, and Part 171 fines/penalties/forfeitures; Part 145 concerns mail importations.
- Treat Post-Summary Corrections as a distinct CBP ACE/entry-summary study topic; verify current eligibility and timing.
- Do not memorize AI-generated question distributions, 'Part 111 = 50%' claims, unverified pass rates, appeal limits, or predicted success percentages.
- Check the official administration-specific CBP reference list, rules, exam notices and deadline before using a study index.
