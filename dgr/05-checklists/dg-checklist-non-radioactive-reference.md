# Dangerous Goods Checklist — Non-Radioactive Shipment (Reference)

Purpose: Reconstructed checklist points for reviewing a non-radioactive dangerous goods shipment before tender, based on IATA's public checklist guidance. Download the official fillable version at the link below for actual use.

## Classification

- [ ] UN/ID number identified and correct for the material
- [ ] Proper shipping name matches the UN/ID number
- [ ] Class or division correctly assigned (plus subsidiary risk, if any)
- [ ] Packing group correctly assigned (where applicable)

## Packing

- [ ] Packing instruction number identified from IATA DGR Section 5
- [ ] Packaging type, marking, and specification match the packing instruction
- [ ] Quantity per package within the limit for the packing instruction
- [ ] Inner packaging compatible with the substance (where applicable)

## Marking and Labeling

- [ ] UN number and proper shipping name marked on the outer package
- [ ] Hazard class label(s) affixed, correct size and orientation
- [ ] Handling labels present where required (e.g., orientation arrows, cargo aircraft only label)
- [ ] Shipper/consignee name and address marked on the package

## Documentation

- [ ] Shipper's Declaration for Dangerous Goods completed and signed (if required for this material)
- [ ] Air Waybill references the dangerous goods shipment correctly
- [ ] Emergency response information included and current
- [ ] Aircraft limitation ("Cargo Aircraft Only" vs. passenger-eligible) correctly indicated

## Operator/State Variations

- [ ] Checked for operator-specific variations (may restrict or add requirements beyond base IATA DGR)
- [ ] Checked for state variations for origin, transit, and destination countries
