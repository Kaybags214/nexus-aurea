Agentic OS — architecture reference

Four layers, built bottom‑up Memory holds the standard. Skills apply it. Routines run it unattended. Applications hand it to someone who never opens a terminal.

An agentic OS is not software you install — it is an assembly order. Nexus Aurea already owns the bottom layer: eleven document lanes of regulatory reference, templates and audit findings. What is missing is everything that turns that reference into repeatable review.

Kernel rule

Build the system before chasing the opportunity.

The ARMS stack

each layer stands on the one below it
L3 Applications The surface. No terminal required.

Where a shipper, a QA lead or a broker actually touches the system. Photograph a document in, severity‑flagged findings out — plus the corrected version.

L2 Routines Scheduled and triggered. Runs while you sleep.

Cloud‑run schedules. This is the layer that converts a tool you remember to open into infrastructure that reports to you.

watchlist_screener run daily market-watch flow brief weekly cold-chain excursion sweep IATA DGR revision watch (annual, 1 Jan) Form 1120 deadline watch
L1 Skills One task, one defined way. Each keeps a learnings file.

The consistency layer. A skill is narrow on purpose — “verify dry ice net weight per package” is a skill; “review this shipment” is not. Each appends what it noticed about its own output quality after every run.

awb-review shippers-declaration-check dry-ice-un1845-weight lithium-battery-section-II commercial-invoice-review coa-review excursion-assessment hs-code-lookup
L0 Memory The substrate. Without it, every session starts from zero.

Already built. Eleven lanes of written standard, and the precedence rule that decides which one wins when two references disagree.

The three gaps it closes

why a folder of notes is not yet an OS

Memory gap

The assistant forgets every conversation by default. Yesterday’s finding on a UN1845 overpack does not inform today’s.

Closed byL0 — a written, versioned reference the agent reads before every review.

Consistency gap

Ask the same question twice, get two different answers. Fatal in a regulated review: a discrepancy found on Monday must be found on Friday.

Closed byL1 — narrow skills with a fixed method and a standard of precedence.

Access gap

Only the person at the terminal can run it. The system cannot be handed to a client, a QA lead, or a second reviewer.

Closed byL2 + L3 — schedules that fire on their own, and an intake anyone can use.
