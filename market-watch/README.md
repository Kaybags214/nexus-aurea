# Market Watch

Purpose: Track selected public companies through filings, fundamentals, risks, ownership, and long-term infrastructure value.

This file is an index. `watchlist.md` is the source of truth for what is tracked and why —
add and edit entries there, not here.

## Files in this folder

| File | What it holds |
|---|---|
| `watchlist.md` | The active watchlist: ticker, sector, reason watching, priority, and per-name risk notes. Also carries the review rules that govern how each class of name is treated. |
| `blockchain-pharma-watchlist.md` | Digital-asset and blockchain-infrastructure watch, focused on supply-chain provenance and pharma traceability. |
| `filing-tracker.md` | Filing-by-filing review log: what was read, the key finding, and the follow-up action. |

| `daily-update-playbook.md` | Defines what each daily run must cover: market data, fundamentals, analyst and ownership data, news, full SEC filing review, crypto network activity, and private-company signals. |

| `SETUP-WALKTHROUGH.md` | Plain-language setup guide for the daily automation. |

## Daily update

An automated update runs Monday through Friday after the U.S. equity close and writes
`screener-reports/report_YYYY-MM-DD.html`. It reads `watchlist.md` and
`blockchain-pharma-watchlist.md`, so adding a name there feeds the report with no other step.

`daily-update-playbook.md` defines what each run must cover: market data, fundamentals, analyst
and ownership data, news, full SEC filing review (10-K, 10-Q, 8-K, DEF 14A, Form 4, Form 144,
S-1/S-3/424B, 13D/13G/13F), crypto market and network activity, and private-company signals.

A second, alerts-only brief built on the Webull Prime endpoints is specified in
`flow-brief-routine.md`. It runs later, writes to a separate directory, and is deliberately kept
independent of the daily report.
