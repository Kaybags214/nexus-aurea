# Air Waybill (AWB) — Reference Template

Purpose: Field-by-field reference for building and reviewing an Air Waybill. Written from IATA Resolution 600a field conventions and major-carrier AWB layouts (not copied from any single proprietary form).

## Header / Identification

- AWB number (11 digits: 3-digit airline prefix + 8-digit serial + check digit)
- Airport of departure (name or 3-letter IATA code)
- Airport of destination
- Issuing carrier name / agent

## Shipper Information

- Shipper's full name, address, city, state, postal code
- Shipper's account number (if applicable)
- Shipper's phone number

## Consignee Information

- Consignee's full name, address, city, state, postal code
- Consignee's phone number
- Consignee's account number (if applicable)

## Agent Information

- Issuing carrier's agent name and IATA code (leave blank if agent has no IATA code)
- Agent's account number
- Agent's IATA cargo agency CASS address

## Routing

- Airport of departure and requested routing
- To / By first carrier
- To / By / To / By (routing for onward carriers)
- Requested flight/date

## Cargo Details

- Number of pieces (RCP)
- Gross weight (kg or lb, specify unit)
- Rate class / commodity item number
- Chargeable weight
- Rate / charge
- Total
- Nature and quantity of goods (dimensions, description)

## Charges

- Weight charge (prepaid / collect)
- Valuation charge
- Tax
- Total other charges due agent / carrier
- Total prepaid / total collect

## Handling Information

- Special handling codes (e.g., dangerous goods reference, dry ice UN1845 quantity, live animals, perishables)
- Reference to related documents (Shipper's Declaration for Dangerous Goods, permits, licenses)
- Free-text instructions to carrier/handler

## Declaration and Signatures

- Shipper's certification statement (accuracy of description, packing, marking, labeling, condition for carriage per applicable DGR/IATA/government regulations)
- Signature of shipper or agent
- Place and date of execution
- Signature of issuing carrier's agent

## Notes for Practice / Review

- Cross-check AWB number against any linked Shipper's Declaration for Dangerous Goods.
- Confirm gross weight and piece count match the packing list.
- Confirm special handling codes match the actual commodity (e.g., ICE/dry ice, RDG, ELI/lithium batteries).
