# Shipper's Declaration for Dangerous Goods (DGD) — Reference Template

Purpose: Field-by-field reference built from IATA DGR public guidance. This is an original summary of required content, not a reproduction of IATA's copyrighted form layout — download the actual fillable PDF from IATA using the link below.

## When Required

A DGD is required whenever dangerous goods are tendered for air transport, including when dry ice or another dangerous good is used only as a coolant for goods that themselves require declaration. (No DGD is needed when dry ice is used solely to refrigerate non-dangerous goods — a Class 9 label and shipping paper marking is still required in that case.)

## Header Fields

- Shipper (full name and address)
- Consignee (full name and address)
- Air Waybill number
- Page number / total pages ("Page 1 of 1 pages" if no extension list)
- Shipper's reference number (optional)

## Transport Details

- Aircraft limitation: "Passenger and Cargo Aircraft" or "Cargo Aircraft Only" (must be explicitly indicated)
- Airport of departure
- Airport of destination

## Dangerous Goods Table (per line item)

- UN or ID number
- Proper shipping name
- Class or division (plus subsidiary risk, if any)
- Packing group (I/II/III, where assigned)
- Type of packing (e.g., inner/outer packaging description)
- Packing instruction number (from IATA DGR Section 5)
- Authorization reference (if goods move under a state or operator variation/approval)
- Quantity and type of packing (net quantity per package, number of packages)

## Additional Handling Information

- 24-hour emergency response telephone number (with ER registrant/provider info)
- Special handling instructions relevant to the shipment
- Overpack indication, if used

## Certification

- Signed declaration statement affirming contents are fully and accurately described, properly classified, packed, marked, labeled, and in proper condition for transport per applicable DGR
- Name of person signing (printed, mandatory)
- Place and date (DD/MM/YYYY, DD.MM.YYYY, or DD/MMM/YYYY format)
- Signature
- Two completed and signed copies must be handed to the operator

## Review / Practice Checklist

- Does the UN number match the proper shipping name and class?
- Is the packing instruction number correct for the packing group and quantity?
- Is "Cargo Aircraft Only" marked when the quantity exceeds passenger-aircraft limits?
- Does the emergency contact number connect to a live 24-hour service?
- Do package marks/labels on the physical package match what's declared on the DGD?
