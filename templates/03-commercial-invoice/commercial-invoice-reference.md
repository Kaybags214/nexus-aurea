# Commercial Invoice — Reference Template

Purpose: Field-by-field reference for international commercial invoices, built from common customs/export documentation requirements (U.S. export.gov, major-carrier guidance). Original summary, not a copy of any single proprietary layout.

## Party Information

- Exporter/seller: full legal name, address, contact info, tax ID (EIN/VAT/EORI as applicable)
- Importer/buyer (consignee): full legal name, address, contact info, tax ID (VAT/GST/EORI/TIN as applicable)
- Notify party (if different from consignee)

## Shipment Reference

- Invoice number and date
- Purchase order / reference number
- Air Waybill or Bill of Lading number
- Country of export
- Country of destination
- Country of origin (per line item, if goods originate from multiple countries)

## Goods Description (per line item)

- Description of goods (plain-language, sufficient for customs classification)
- HS code (Harmonized System tariff classification — export and import country codes may differ)
- Quantity and unit of measure
- Unit price and currency
- Line total
- Country of origin/manufacture

## Totals and Charges

- Total value of goods
- Currency of sale
- Freight charges
- Insurance charges
- Other charges (handling, packing)
- Incoterms (e.g., FOB, CIF, DAP) defining buyer/seller responsibility split
- Total invoice value

## Shipment Details

- Number of packages
- Total gross weight / net weight
- Type of shipment (e.g., sale, sample, gift, repair/return)
- Port/airport of loading and discharge

## Declaration

- Statement certifying the invoice is true and accurate
- Signature and printed name of authorized company representative
- Date

## Review / Practice Checklist

- Do HS codes match the goods description (not just copied from a prior shipment)?
- Does total invoice value match the sum of line-item totals plus stated charges?
- Are Incoterms specified and consistent with the freight/insurance charge allocation?
- Does country of origin match any certificate of origin on file?
