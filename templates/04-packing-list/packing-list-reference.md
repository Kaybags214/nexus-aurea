# Packing List — Reference Template

Purpose: Field-by-field reference for export/import packing lists, built from common carrier and freight-forwarder documentation standards. Original summary, not a copy of any single proprietary layout.

## Party Information

- Shipper name, address, contact info
- Consignee name, address, contact info
- Notify party (if different)

## Shipment Reference

- Packing list number and date
- Related invoice number
- Related Air Waybill / Bill of Lading number
- Order/PO reference number

## Package-Level Detail (per package)

- Package/carton number (marks and numbers)
- Package type (carton, pallet, drum, crate, etc.)
- Dimensions (L x W x H, with unit)
- Net weight
- Gross weight

## Line-Item Detail (per item, mapped to package number)

- Item description
- HS code (if included alongside invoice)
- Quantity and unit of measure
- Which package number(s) the item is packed in

## Totals

- Total number of packages
- Total net weight
- Total gross weight
- Total volume (cubic meters or cubic feet)

## Special Handling Notes

- Stacking/handling instructions
- Reference to dangerous goods documentation, if applicable (UN number, class)
- Temperature control requirements, if applicable

## Declaration

- Shipper's declaration/signature confirming accuracy of packing details
- Date

## Review / Practice Checklist

- Does the sum of per-package weights match the stated total gross/net weight?
- Does every line item map to an actual package number?
- Does the total package count match the count declared on the Air Waybill?
- If dangerous goods are packed, does the packing list cross-reference the DGD?
